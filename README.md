# 🏦 Bank CRUD System

A simple Online Banking System developed using FastAPI, MySQL, HTML and CSS.

## 📌 Project Description

This project is a basic banking system with separate User and Admin features.

### 👤 User Features
- User Login
- View Account Details
- View Account Balance
- Deposit Money
- Withdraw Money
- View Transaction History
- Logout

### 🛡️ Admin Features
- Admin Login
- Create Bank Account
- View All Bank Accounts
- View All Transactions
- Delete Bank Account
- Logout

## 🛠️ Technologies Used

- Python
- FastAPI
- MySQL
- HTML
- CSS
- Jinja2
